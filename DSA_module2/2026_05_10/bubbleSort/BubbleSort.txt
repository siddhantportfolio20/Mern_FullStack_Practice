🧠 Bubble Sort – Steps
        1. Take the array of elements to be sorted
        2. Start from the first element
        3. Compare the current element with the next element
        4. If the current element is greater than the next element, swap them
        5. Move to the next position and repeat the comparison
        6. Continue this process till the end of the array
            → The largest element will be placed at the last position
        7. Repeat the above steps for the remaining unsorted part of the array
            → Ignore the last sorted elements after each pass
        8. Continue the passes until:
        9. All elements are sorted, or No swaps occur in a pass (array is already sorted)




🧠 Example

arr = [5, 3, 2]

    🔁 Pass 1 (i = 0)
    
    👉 Range: j = 0 → 1
    
    Step 1:
    i = 0, j = 0, j+1 = 1
    Compare: arr[0] = 5 and arr[1] = 3
    5 > 3 → swap
    
    👉 Array becomes: [3, 5, 2]
    
    Step 2:
    i = 0, j = 1, j+1 = 2
    Compare: arr[1] = 5 and arr[2] = 2
    5 > 2 → swap
    
    👉 Array becomes: [3, 2, 5]
    
    ✅ After Pass 1 → largest element (5) fixed at end
    
    🔁 Pass 2 (i = 1)
    
    👉 Range: j = 0 → 0
    
    Step 1:
    i = 1, j = 0, j+1 = 1
    Compare: arr[0] = 3 and arr[1] = 2
    3 > 2 → swap
    
    👉 Array becomes: [2, 3, 5]
    
    ✅ After Pass 2 → array sorted
    
    🔁 Pass 3 (i = 2)
    No comparisons needed
    ✅ Final Answer
    
    [2, 3, 5]
