What is jsx :-> 
->  JavaScript XML - its a syntax extension that allows us to write HTML like code inside JS.
->  React uses babel for understanding/converting JSX 


Rules of JSX ?
->1 Jsx must return a single root element. either wrap them in div or <> </> this are called as fragment
->2 When you want to your class you will not write class keyword you should write className 
->3 Self closing tags must have a slash at the end (<img src="" alt="" />)   
->4 If statement are not used in jsx
->5 Whenever you create a jsx components the first letter should be Capital
->6 Inline styling in components are in a object format with key value pairs
