splice : 

        it is used to mutate /change the original array 
        it returns an array of removed elements

        used :- 
                remove elements from an array 
                add new elements to an array

        Syntax :- 
                arr.splice(startIndex , delete count , item1,item2,item3....)
                start point(required) 
                delete count :- how many elements you want to remove (optional , default from start )
                elements to add from start index(optional)
